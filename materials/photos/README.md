# 워너비홈케어 사진 (AI 연출 이미지)

Gemini 로 만든 연출 이미지입니다. 실제 작업 기록이 아닙니다. 사용자가 만들어 제공했습니다(2026-11-19).

2026-11-20 고객 작업지시서로 메뉴와 메인 구성이 바뀌어 자리와 파일 이름을 다시 맞췄습니다. Phase 1 에서 쓰는 사진은 5장이고 2장은 준비 중입니다. `phase2/` 는 카테고리 화면(Phase 2)에서 쓸 사진입니다.

## 쓸 때

- 원본(PNG)은 이 폴더에 그대로 둔다. 사이트에는 같은 크기의 WebP 로 바꿔 `public/photos/` 에 같은 이름으로 넣는다.
- 자르기·덧칠·합성으로 사진 내용을 바꾸지 않는다. 오른쪽 아래의 Gemini 표시를 지우지 않는다. 화면 칸에 맞춰 보이는 범위를 정하는 것(`object-fit: cover`, 기준점, 확대)은 괜찮다.
- 푸터에 "일부 이미지는 AI로 제작한 연출 이미지입니다." 를 항상 보여 준다.
- 실제 작업 전·후 사진이나 고객 후기 사진처럼 소개하지 않는다. 후기 칸, 인스타그램 칸, 전·후 사진 칸에는 넣지 않는다.
- 상태가 '준비 중'인 파일은 아직 없다. 고객이 실제 작업 사진을 보내기로 했다. 그 자리는 "사진 준비 중" 한 줄만 있는 자리표시로 둔다(카드는 `brand-100` 바탕, 히어로는 `brand-950` 바탕). 다른 사진으로 대신 채우지 않는다.
