# 워너비홈케어 로고 (임시 벡터)

고객이 메신저로 보낸 로고 이미지(`logo-original.png`)를 따서 만든 임시 SVG입니다.
고객에게 로고 원본 파일(AI·SVG·고해상도 PNG)을 받으면 이 폴더의 파일을 교체합니다.

## 색 (이미지에서 직접 잰 값)

| 부분 | 값 |
| --- | --- |
| 심볼(집 + WB) | `#356BA7` |
| 글자(워너비홈케어 · WANNA.B HOMECARE) | `#142A4F` |

## 파일

| 파일 | 쓰임 |
| --- | --- |
| `logo-horizontal.svg` | 헤더용 가로 조합(심볼 + 한글 글자). 원본에 가로형이 있으면 교체 |
| `logo-vertical.svg` | 원래 세로 조합(심볼 + 한글 + 영문). 푸터·소개 페이지 |
| `logo-mark.svg` | 심볼만. 파비콘·앱 아이콘·좁은 자리 |
| `*-white.svg` | 어두운 배경용(전체 흰색) |
| `logo-original.png` | 받은 이미지에서 잘라낸 원본(대조용) |

## 쓸 때

- 로고의 색·비율·글자 모양을 바꾸지 않는다. 배경에 따라 컬러판과 흰색판 중에서만 고른다.
- 로고 둘레에 심볼 창문 한 칸 너비 이상의 여백을 둔다.
