## 확인 중 찾아 고친 것

- 카테고리 화면 질문 답이 `<p>` 안에 `<div>` 로 들어가 하이드레이션 오류가 났음 → 감싸는 태그를 `div` 로.
- PC 에서 히어로 글 영역이 사진 위를 덮어 '작업 영상 보기' 버튼이 눌리지 않았음 → 버튼을 위로 올림.
- 원칙·작업 사진 번호 색 대비 부족(`brand-500`) → `brand-600`.
- 질문 답을 열 때만 그리던 것을, 숨긴 채로 HTML 에 넣음(검색·대조용).
- 왜 필요한가요 카드의 제목 순서(h1 → h3) → 화면 읽기용 h2 추가. 후기 넘김 점 버튼 크기 24px.
- `/terms` 의 `<a href="/privacy">` → `Link`(새 동적 경로 때문에 lint 규칙에 걸림).
- 관리자 화면이 새로 그리기(router.refresh)를 기다리다 버튼이 잠기는 문제 → 서버 액션이 바뀐 목록을 돌려주고 화면이 바로 반영.

## 가정·바꾼 점

- 새 전·후 짝·후기는 **숨김으로 저장**하고, 확인한 뒤 공개를 켜게 했습니다.
- 후기 카드: 캡처 칸 높이를 고정(PC 230px·휴대폰 190px)하고 그 안에 원래 비율로 넣었습니다. 긴 캡처도 자르지 않고 줄여 보이며, 누르면 크게 봅니다.
- 컬비 '케어 전/후', 줄눈·탄성·새집 '시공 전/후' 배지는 짝이 생기면 나옵니다.
- 카테고리 화면 아래 견적 띠의 설명은 메인 견적 블록의 문장("몇 가지만 고르면 접수됩니다. 내용을 확인한 뒤 상담사가 연락드립니다.")을 그대로 썼습니다. 새로 쓴 문장은 슬라이더 안내 "손잡이를 좌우로 움직여 보세요"와 전·후 자리표시 "실제 사진을 받으면 채웁니다" 뿐입니다.
- 청소 범위 사진 오른쪽 위에 '실제 현장 사진' 라벨을 달았습니다(묶음 `kind: real`).
- 탄성코트 '펄' 무늬는 이름·설명에 '펄·진주'가 있는 견본(진주 화이트)에만 씁니다. 전구색은 `--color-warm-light` 토큰의 반투명 겹침입니다.
- 묶음의 `customerSpots`·줄눈 `beforeAfter.tabs`·`waiting`·`source` 는 화면에 내보내지 않습니다(참고·점검용).
- 저장소 검사의 3자리 색 값 규칙이 해시태그 `#100%직영팀` 을 색으로 잘못 읽어, 뒤에 `%` 가 오면 색이 아니라고 고쳤습니다(예외 추가가 아니라 규칙 정밀화).
- 아이콘은 프로젝트 규칙대로 `@/components/icons` 를 거쳐 가져옵니다.
- 마이그레이션 목록을 볼 때 한 번 DB 비밀번호를 명령 인자로 넘겼습니다(Codespace 안, 출력·기록 없음). 그 뒤로는 환경변수로만 넘겼습니다.
- 묶음 문구에서 고칠 점으로 보이는 것은 없었습니다(맞춤법은 묶음에서 이미 다듬음). 다만 청소 '무엇이 다른가요' 본문과 질문 6 답이 같은 글이라, 고객 확인 때 한쪽만 바꾸지 않도록 함께 봐 주세요.

## 관리자에서 해 본 단계(클릭 순서)

1. `/admin/login` 에서 비밀번호 입력 → [로그인]
2. 왼쪽 메뉴 '사이트 설정 › 전·후 사진'
3. '새 짝 추가'에서 서비스 '청소', 이름 '시험', 설명 '시험', 전·후 사진(묶음의 주방 전·후) 고르기 → [저장]
4. 목록의 '시험' 줄에서 [숨김] → '공개 중'
5. [공개 중] → '숨김'
6. [삭제] → 확인 창 [확인]
7. 왼쪽 메뉴 '사이트 설정 › 고객 후기'
8. '새 캡처'에서 캡처 파일(묶음의 가린 후기 1장) 고르기 → 이름 '시험', 서비스 '청소' 체크 → 캡처 위 왼쪽 위를 끌어 사각형 1개 → [가린 결과로 저장]
9. 목록의 '시험' 줄에서 [숨김] → '공개 중'
10. [공개 중] → '숨김'
11. [삭제] → 확인 창 [확인]

걸린 단계: 처음 실행 때 후기 10단계 뒤 [삭제] 버튼이 잠긴 채로 남았습니다(화면 새로 그리기 대기). 위 '고친 것'의 마지막 줄처럼 고친 뒤 실제 주소에서 처음부터 끝까지 통과했습니다. 그때 남은 시험 후기 2개는 지웠고, 시드 항목은 건드리지 않았습니다.
