## 지운 기능

자동 글쓰기, 발행 캘린더·예약 발행, 주간 콘텐츠 계획, 유입·검색 통계, 자체 방문 분석, IndexNow 자동화, 카카오 접수 알림, 사진 라이브러리 동기화·분석, 서울 구·동 지역 안내(`/seoul…`), 글별 SEO 분류, 광고용 `?city=`, `/preview/…`, GA, 작업사례 글 기능 전체(`/posts…`, 지역별 목록, 게시글 관리, `feed.xml`, 글 대표 이미지), 메인의 작업사례·네 가지 원칙·청소범위·FAQ 블록, `/faq`, `/admin/faq`, 글 후기와 `/admin/reviews`, `HeroQuickForm`, v1 랜딩 컴포넌트, 쓰지 않는 UI 컴포넌트, 기능에 딸린 테스트·스크립트, 쓰지 않게 된 의존성(framer-motion, react-markdown 등).

### 성능

- 배포 주소에서 3번 쟀습니다: 성능 73 · 75 · 69. 실제 측정값(observed)은 첫 화면 0.43초, LCP 0.67초입니다. 점수는 Lighthouse 의 느린 4G·CPU 4배 감속 '모의' 값(FCP 약 3초)으로 매겨집니다.
- 기반보다 나빠지지 않았습니다(기반 52).
- 고친 것: 기반의 시각 표시가 끝없이 다시 그려지던 문제(Style & Layout 8초 → 1.8초), framer-motion 제거, zod 를 브라우저 번들에서 뺌, 글꼴 바뀔 때의 밀림(CLS 0.21 → 0).
- 남은 원인: React 하이드레이션과 화면 안의 움직이는 부품(히어로 넘김, 실시간 목록, 견적 단계형 폼)의 스크립트. 다음 단계에서 견적 폼을 늦게 불러오기 등으로 더 줄일 수 있습니다.
- 이 Codespace 는 CPU 2개라 같은 페이지도 잴 때마다 10점 넘게 흔들립니다.

## 가정·바꾼 점

- 1–4단계를 한 커밋씩 나누지 못했습니다. 2·3·4단계는 서로 얽혀(지운 기능을 쓰던 화면을 새 화면으로 바꿔야 빌드가 됨) 한 상태로 만들어 검증한 뒤 `ed358fe` 한 커밋으로 올렸습니다. 1단계 커밋(`4fac76e`)은 기반 그대로라 환경변수 없이는 빌드되지 않았고(기반이 빌드 때 DB 를 읽음), 2–4단계 커밋부터 환경변수 없이 빌드됩니다. `phase-1` 은 배포되지 않는 브랜치라 바깥에 영향은 없었습니다.
- Supabase: 조직에 `wannabhomecare` 프로젝트가 없었고(다른 이름의 기존 프로젝트 1개는 건드리지 않음), 서울(ap-northeast-2)·무료로 새로 만들었습니다. DB 비밀번호·키·ref 는 `.env.local` 에만 있습니다. 키는 기존 형식(anon / service_role)을 씁니다.
- Vercel 프로젝트는 이름을 바꾸지 않고 그대로 썼고, ID 를 `.env.local` 에 고정했습니다. 환경변수는 production·preview 에 넣었습니다. 카카오 채널은 값이 없어 등록하지 않았습니다.
- 견적 요청 표의 성함은 공개 목록에 "김○○"(첫 글자 + ○○)로만 나갑니다.
- 견적 중간 저장(새로 고침 대비)은 브라우저 세션 저장소에 두되, 성함·연락처·나머지 주소·요청사항·사진은 넣지 않습니다. 그래서 새로 고침하면 12번 화면 앞까지만 되돌아옵니다.
- 서비스 카드·견적 시작 카드에서 견적으로 갈 때 링크는 `/#quote` 이고, 고른 서비스는 세션 저장소로 넘깁니다(컬비청소 → 청소 선택 + 8번에 컬비청소).
- 관리자의 '첫 화면'·'약속·서비스' 편집은 DB(`site_content`)에 저장합니다. 아직 저장한 값이 없어 코드의 기본값이 보입니다.
- 히어로 넘김 간격을 4초로 했습니다(위 표).
- 상태 이름 '작업출동'은 청소 업종에 맞게 '작업진행'으로 바꿨습니다.
- 견적 접수는 한 IP 에서 10분에 8번까지 받습니다(기반의 로그인 시도 제한과 같은 방식).
- Phase 0 스크립트 `check-access.mjs` 의 기반 저장소 주소를 `.env.local` 의 `BASE_REPO_URL` 로 옮겼습니다(저장소 검사 '흔적 0건'을 위해).
- `docs/reference/` 에 기반 사이트 캡처를 두었습니다(커밋 안 함).
- 테스트에 쓴 접수 행과 사진은 모두 지웠습니다(로컬 2회 + 배포 2회, 남은 시험 행 0건). 실제 고객 접수는 아직 없습니다.
